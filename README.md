# FDE 특허·연구 작업공간 — 가상 데이터 시연

보고서를 납품하고 끝나는 IP-R&D를, 연구자가 필요한 순간에 결과를 찾고 질문하며 다음 연구 행동으로 이어 가는 **작업공간**으로 바꾸는 경험을 가상 데이터로 보여 주는 시범 프로그램입니다.

> **모든 문헌·출원인·과제·보고서·검토 의견은 가상입니다.** 질문 응답은 규칙 기반이며, 실제 AI·특허 DB·사용자 인증·서버는 연결하지 않았습니다. 가상 데이터로 분석 정확성이나 사업 성과를 입증했다고 해석하지 마세요.

## 바로 실행

`index.html`을 Chrome·Edge 등 브라우저로 여세요. 설치·API 키·로그인·서버가 필요 없습니다.
상단 **초기화** → **시연 가이드**를 누르면 9단계 순서를 안내합니다.

## 무엇을 본떠 만들었나

실제 IP-R&D 중간보고(공구 없이 재구성하는 가구, 4개 기술축)의 **분석 구조·흐름·분포**를 본떠 가상 데이터를 만들었습니다.
실제 고객명·특허번호·실존 기업·권리자는 쓰지 않았고, 원본 보고서 파일은 저장소에 넣지 않았습니다(상표조사 부분은 제외).

| 중간보고의 내용 | 시연에서의 구현 |
|---|---|
| 4개 기술축(A 모듈 수납장·B 성장형 의자·C DIY 테이블·D 무공구 커넥터)과 결합(K)·성능(P)·사용(U) 태그 | 문헌마다 기술축·세부코드 1개 + 태그 여러 개. 결합방식은 중복 포함 집계 |
| 검색 → 정제 → 관련 → Core 판정 | 분석 리포트의 "검색에서 분류까지"(검색·정제는 가상 구축 기록, 관련·Core는 배열에서 계산) |
| 결합방식별 문헌 수, 5년 단위 출원 동향, 국가별 구성, 제품군별 Core | 질문형 카드 12개와 물어보기 질문 |
| 결합방식 비중 추세(형상맞물림·자석) | 시기별 비중 선 그래프 |
| 권리 상태, 해외 특허의 국내 영향, 국내 주의 특허, 만료 예정 캘린더 | 상태·만료연도·한국 가족특허 여부로 계산 |
| 출원인 구조, 기술 공백(결합방식 × 제품) | 출원인 상위 10, 존속 권리 기준 히트맵 |
| 대표 시사점 6가지 | 계산된 수치를 끼워 넣는 고정 문장(기준선이 바뀌면 함께 바뀜) |
| 신규 IP 창출: 벤치마킹 → 약점 5 → 개선안 5 → 보강 기술 8 → 청구항 초안 → 회피 점검 | "신규 IP 창출" 화면 (모두 가상 예시) |
| 국내 핵심 특허 청구항 대조(상·중·하) | 대조표 — 위험도는 컨설턴트가 공개해야 연구자에게 보임 |

## 시연 순서 (9단계)

1. **발견** — 오늘 볼 것에서 과제를 고르고 질문형 카드를 엽니다.
2. **분석 한눈에** — 분석 리포트에서 핵심 수치·시사점·카드 그래프를 봅니다.
3. **질문·추세** — "출원 추세를 보여 주세요" → 5년 단위 그래프, 실행 번호.
4. **후속 조건** — "그중 국내만" → "패밀리 단위로 보여 주세요" → "해외 특허가 국내 사업에 영향을 주나요?"(새 주제, 조건 해제 표시).
5. **근거·저장** — 근거 문헌의 과제·구성·효과·태그·권리 상태·가상 청구항 확인 → 저장 → CSV.
6. **전문 검토** — "레버 클램프가 특허에 걸리나요?" → 자동 결론 없이 검토 요청 → 컨설턴트가 가상 답변 공개 → 연구자 화면에 도착.
7. **신규 IP 창출** — 개선안과 보강 기술, 청구항 초안, 국내 핵심 특허 대조표(공개 전 위험도 숨김).
8. **갱신** — 작업대에서 신규 10건 검토 → V2 공개 → 공백 변화·과제 영향 "확인 필요".
9. **과거·최신 비교** — 저장 결과의 V1 수치 보존 확인 → 최신 기준선 재실행 → 비교.

추가 질문: "자석 결합만 조사했다면 무엇을 놓쳤나요?", "국내 핵심 특허를 보여 주세요", "만료 예정 캘린더", "결합방식 비중 트렌드", "출원인별로 보여 주세요", "공백 후보를 보여 주세요", "의자 관련 결합방식은?", "개선안을 보여 주세요", "DEMO-KR-0001", "조건 초기화". 지원하지 않는 질문에는 답을 꾸며내지 않고 가능한 질문을 안내합니다.

**시연 후 받을 피드백**: 무엇을 다시 찾아보고 싶은지, 원문이 이해에 충분한지, 어떤 질문이 전문 검토로 넘어가야 하는지, 갱신 안내가 연구 행동을 바꾸는지.

## 디자인

- 짙은 남색 사이드바와 아이콘 메뉴, 반투명 헤더, 그라데이션 히어로(첫 화면)와 핵심 수치 타일.
- 그래프는 **한 가지 색조(파랑) 안의 그라데이션** 막대에 둥근 끝, 옅은 눈금선, 등장 애니메이션(동작 줄이기 설정 시 끔), 막대에 마우스·키보드 포커스를 두면 수치 툴팁. 모든 수치는 그래프 아래 표에도 있습니다.
- 시기별 비중은 두 방식(형상맞물림·자석)만 선으로 강조하고 나머지는 표로 둡니다.
- 공백 분석은 파랑 단계 히트맵. 관측 0 칸은 빗금과 점선 테두리로 색 없이도 구분됩니다.
- 외부 글꼴·라이브러리 없이 CSS와 인라인 SVG만 사용합니다(설치 없는 실행 유지).

## 검증 결과 (2026-09-30)

### 실제로 확인한 것

- `node tests.cjs` — **20 / 20 통과**. 기준 건수와 데이터 무결성(가상 표기, 한국 가족특허 표시), 구간·제품군·국가·상태·결합방식 집계의 독립 계산 일치(결합방식 중복 포함), 후보 제외, 후속 필터, 패밀리 중복 제거, 범위 유지·새 주제 조건 해제 표시, 저장 결과 불변, 재실행 새 ID, 검토 요청 중복 방지, 가상 답변 공개, V2 공개 조건, 과제 영향·공백 변화, CSV 이스케이프, 입력 이스케이프, 지원 외 질문, 저장소 실패, 해외 특허 국내 영향 단계 수치, 비중 추세·만료 캘린더, 대조표 예비 분류 규칙·공개 전 비공개, 시사점 수치.
- `node e2e.cjs` — **22 / 22 통과** (Chromium, Playwright 1.56). 초기화부터 9단계를 실제 화면에서 클릭으로 조작, 화면 수치를 엔진 독립 계산과 대조, 막대 툴팁, CSV 실제 다운로드, 대조표 위험도가 공개 전 연구자에게 보이지 않음, V2 후 분석 리포트 재계산, 새로고침 후 상태 유지, 모바일 폭 390px에서 8개 화면 가로 넘침 없음, 키보드 이동, `localStorage` 차단 시 동작, 콘솔 오류 없음.

### 확인하지 못한 것

- Chrome·Edge·Safari 실제 데스크톱 앱에서의 다운로드 대화상자·글꼴 표시 (검증은 headless Chromium).
- 화면 낭독기(스크린 리더) 사용성, 고대비 모드.
- 내려받은 CSV를 Excel에서 열었을 때의 표시(UTF-8 BOM을 넣었지만 Excel로 직접 열어 보지는 않음).
- 가상 데이터의 분포는 중간보고의 비율을 흉내 냈을 뿐이며 수치가 같지 않습니다(예: 미국 비중 46%, 중간보고는 57%).
- **의뢰인 시연 전에 실제로 사용할 브라우저와 화면에서 9단계를 한 번 리허설하세요.**

## 실제 데이터로 넘어갈 다음 단계

1. 실제 자료의 일부 구간을 골라 기술분류·원문·보고서 카드의 연결을 복원합니다.
2. Excel 열 매핑, 출원인 정규화, 중복·패밀리 규칙, 세 축 등급의 근거를 확인합니다.
3. `fde-data`의 가상 데이터를 교체하고 `tests.cjs`의 기대값을 실제 집계로 바꾼 뒤 같은 사용자 흐름으로 실증합니다.
4. 그다음에 기관 권한, 서버 인증·접근 통제, 분석·승인 이력, 데이터 이용권한, AI 사용 범위, 수집·갱신 운영을 설계합니다.
